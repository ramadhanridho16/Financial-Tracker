# Purpose

Financial Tracker berbasis Google Spreadsheet.

Menggunakan Natural Language Parser untuk mencatat transaksi.

---

# Goal

Mengurangi jumlah klik.

Mengurangi penggunaan Form.

Semua transaksi dapat dicatat menggunakan satu kalimat.

---

# Features

- Transaction
- Wallet
- Budget
- Loan
- Dashboard
- Report

---

# Users

Personal Use Only

---

# Non Goals

❌ ERP

❌ Multi User

❌ Online Database
